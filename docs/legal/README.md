# الشروط والأحكام وسياسة الخصوصية — الإصدار 1

هذه نسخة المراجعة من الإصدار الأول. **النص المنشور يعيش في قاعدة البيانات**
(`legal_documents`، الترحيل 0083)، وكل تعديل بعد الإطلاق يُنشر من لوحة التشغيل ←
«الشروط والسياسات» كإصدار جديد. لا تعدّل هذه الملفات لتغيير ما يراه المستخدمون.

| الملف                                           | المستند                                      |
| ----------------------------------------------- | -------------------------------------------- |
| `terms.ar.md` / `terms.en.md`                   | الشروط والأحكام                              |
| `privacy.ar.md` / `privacy.en.md`               | سياسة الخصوصية (نظام حماية البيانات الشخصية) |
| `provider_terms.ar.md` / `provider_terms.en.md` | شروط مقدّمي الخدمة                           |

النص العربي هو المعتمد. تُملأ `{{company}}` و`{{cr}}` و`{{address}}` من الإعدادات ←
«الشروط والخصوصية»، و`{{email}}` و`{{phone}}` من أرقام الدعم، و`{{dispute_window_days}}`
و`{{auto_complete_hours}}` من الإعدادات نفسها التي يطبّقها النظام، فلا يختلف النص عن
سلوك التطبيق.

⚠️ كُتبت لتحمي هبّة وتطابق ما يفعله التطبيق فعلاً، لكنها ليست استشارة قانونية. راجعها
مع محامٍ مرخّص في المملكة قبل الإطلاق، وخصوصاً: نموذج الحجز والتحصيل (ADR-0008)،
ونقل البيانات خارج المملكة (ADR-0010)، وحدود المسؤولية، ومدة عدم الالتفاف على المنصة.
